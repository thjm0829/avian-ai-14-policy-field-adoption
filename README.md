# 14. 정책·제도 및 현장 적용성

> **작성 상태:** 세부 내용 작성 완료  
> **작성 기준일:** 2026년 8월 27일  
> **핵심 전제:** 본 시스템은 고병원성 조류인플루엔자(HPAI)를 확진하거나 법정 방역조치를 자동 결정하는 장비가 아니다. 농장 분변의 반복 신속항원검사, 자동재검과 시계열 경보를 통해 공식검사가 필요한 농장의 우선순위를 판단하도록 지원하는 예찰보조 시스템이다.

## 핵심 결론

본 사업의 제도 적용 목표는 새로운 민간 방역체계를 만드는 것이 아니라, 기존 국가 조류인플루엔자 방역체계 앞단에 반복 가능한 농장 예찰정보를 제공하는 것이다.

따라서 제도 적용성은 다음 다섯 조건을 동시에 충족할 때 성립한다.

1. 장치 결과와 공식검사 결과의 권한을 명확히 구분한다.
2. 법정 신고와 가축방역관의 판단을 장치 결과가 지연하거나 대체하지 않는다.
3. 제품의 사용목적, 키트 결합방식, 자동전처리와 소프트웨어 역할에 대한 규제분류를 사전에 확정한다.
4. 시료·폐기물·개인정보·농장정보를 단계별로 안전하게 관리한다.
5. 전문기관 검증과 유료실증을 통과한 뒤 공공조달 경로를 순차적으로 적용한다.

> **제도 적용 기본흐름**  
> 농장 자동예찰 → 품질확인 및 자동재검 → 관리자 확인 → 공식검사 필요성 알림 → 기존 신고·정밀검사 체계 연결 → 공식기관의 판단과 방역조치

### 제도상 제품 위치

| 구분 | 본 시스템이 수행하는 역할 | 수행하지 않는 역할 |
|---|---|---|
| 예찰 | 농장 단위 반복검사, 기준선과 변화추세 관찰 | 농장 안전 확인 또는 감염 부재 보증 |
| 검사 | 상용 AIV 신속항원키트의 자동 전처리·판독·재검 | 국가 정밀진단 또는 확진 |
| 경보 | 재검, 관리자 확인, 공식검사 연결 필요성 제시 | 이동제한·살처분·역학조사 자동 결정 |
| 데이터 | 장치·시료·키트·경보 이력의 추적관리 | 권한 없는 KAHIS·차량이동정보 접근 |
| 공공서비스 | 방역자원의 우선순위 판단 지원 | 법정 방역기관의 지휘·책임 대체 |

### 변경할 수 없는 운영원칙

- Negative 결과를 감염 부재나 신고면제의 근거로 사용하지 않는다.
- 폐사, 산란율 저하, 사료·음수 감소, 임상증상 등 신고사유가 있으면 장치 결과와 관계없이 기존 공식절차를 따른다.
- Positive·Uncertain·반복 Invalid는 확진이 아니라 재검과 공식 확인이 필요한 신호로 표현한다.
- 실제 감염성 AIV 시료는 승인된 전문기관과 적절한 생물안전시설의 절차 안에서만 취급한다.
- 공식 방역정보는 법적 근거와 제공기관의 승인이 확인된 최소 항목만 사용한다.
- 제품분류와 허가범위가 서면으로 확인되기 전에는 상용 판매와 효능표현을 확정하지 않는다.
- 벤처나라·혁신제품 등 조달제도는 진입경로이며 구매보장으로 표현하지 않는다.

## 14.1 기존 AI 방역체계와의 연계

### 1. 용어와 연계원칙

본 절의 AI는 Artificial Intelligence가 아니라 Avian Influenza, 즉 조류인플루엔자를 의미한다. 시스템에 적용되는 영상판독·위험산정 알고리즘은 별도의 소프트웨어 기능으로 구분한다.

현행 조류인플루엔자 방역체계는 농장 등의 신고, 시·군 및 시·도 가축방역기관의 초기조치, 가축방역관의 현장검사와 시료채취, 검역본부 또는 지정 정밀진단기관의 정밀검사, 관계기관의 이동제한·역학조사·살처분 등 법정조치로 구성된다.

본 시스템은 이 체계를 우회하지 않고 신고 이전의 일상예찰과 신고·정밀검사 연결 구간을 보조한다.

### 2. 기존 체계와 제품의 연결위치

| 단계 | 기존 방역체계 | 본 시스템의 지원 | 최종 책임 |
|---|---|---|---|
| 일상관리 | 농장주의 임상관찰·차단방역 | 자동 분변검사, 장치 QC, 시계열 기준선 | 농장 운영자 |
| 이상탐지 | 폐사·산란·사료·음수 이상 확인 | Positive·Uncertain·변화추세 탐지, 자동재검 | 농장 운영자·서비스 운영자 |
| 신고·통보 | 관할 시·군, 시·도 가축방역기관 등에 신고 | 경보 시각·시료·Kit Lot·판독근거 제공 | 법정 신고의무자 |
| 현장조사 | 가축방역관 출동, 임상검사, 공식 시료채취 | 장치기록과 최근 추세의 참고자료 제공 | 시·도 가축방역기관 |
| 정밀검사 | 검역본부 또는 지정기관의 정밀진단 | Paired Result 확보와 사후 성능평가 | 공식 진단기관 |
| 방역조치 | 이동제한·소독·역학조사·살처분 등 | 조치결과 기록연계는 승인 범위에서만 수행 | 정부·지자체·가축방역기관 |

### 3. 현장 경보 처리흐름

1. 장치가 정해진 Sampling Point에서 Composite Sample을 채취한다.
2. 전처리, 신속항원검사, C/T선 영상판독과 QC를 수행한다.
3. Invalid는 감염경보와 분리하여 재촬영·재검 또는 장치점검으로 처리한다.
4. Positive·Uncertain 또는 위험보조정보 변화가 확인되면 자동재검한다.
5. 1차·재검 결과, 신호강도, QC와 장치상태를 관리자에게 함께 표시한다.
6. 관리자는 농장 임상·생산정보와 함께 확인하되 법정 신고사유가 있으면 즉시 기존 신고절차를 따른다.
7. 공식기관에는 승인된 서식과 채널로 필요한 최소정보만 제공한다.
8. 공식검사 결과를 확보한 경우 장치결과와 Pairing하여 성능검증에 사용한다.

자동재검은 공식신고를 늦추기 위한 대기절차가 아니다. 폐사 증가나 뚜렷한 임상증상처럼 즉시 신고가 필요한 상황에서는 재검 완료를 기다리지 않는다.

### 4. 기관별 역할

| 주체 | 주요 역할 | 사전 확정사항 |
|---|---|---|
| 참여농가 | 설치협조, 차단방역, 알림확인, 법정 신고 | 담당자, 접근구역, 경보수신, 중단권한 |
| 개발·운영사 | 장치운영, 유지보수, QC, 데이터보호 | SLA, 장애·보안사고 대응, 제품책임 |
| 키트 제조·공급사 | 허용검체·IFU·Lot·보관조건 제공 | 자동전처리·판독 결합에 대한 기술검토 |
| 전문기관 | 기준검사, 검체·성능·생물안전 검증 | 시험계획, Label, 결과공유, 논문화 범위 |
| 지자체·가축방역기관 | 공식 절차와 현장연계 검토 | 신고채널, 담당부서, 출동·확인 기준 |
| 검역본부 | 제품분류·허가·방역체계 관련 협의 | 사용목적, 품목, 임상·기술문서 경로 |
| 조달·수요기관 | 실증·구매·성과평가 | 계약목적, 규격, 검수, 데이터·책임범위 |

역할표는 양해각서만으로 끝내지 않고 실증협약, 데이터처리계약, 시험계획서, 운영 SOP와 공공계약 특수조건에 반영한다.

### 5. 데이터 연계 단계

공식 데이터 접근을 사업의 선행조건으로 가정하지 않는다.

| 단계 | 사용 데이터 | 적용조건 |
|---|---|---|
| 1단계 | Mock 농장·차량·위험정보 | 알고리즘과 화면흐름 검증 |
| 2단계 | 참여농가가 적법하게 보유한 생산·출입정보 | 계약·동의·목적·보유기간 확정 |
| 3단계 | 전문기관의 시험·공식검사 결과 | 시험계획과 결과공유 승인 |
| 4단계 | 지자체·공공기관의 최소 공식정보 | 법적 근거, 제공권한, 보안조건 확인 |
| 5단계 | 지역 단위 연계 | 공공실증 성과와 보안·영향 검토 통과 |

KAHIS나 차량이동정보와의 API 연계는 공개 여부만으로 판단하지 않는다. 정보 보유기관의 권한, 이용목적, 제공범위, 보안등급과 계약을 확인한 뒤 별도 과제로 추진한다.

### 6. 제도 연계 금지사항

- 장치 경보를 공식 의사환축 판정이나 확진처럼 표시
- 장치 음성을 근거로 신고·출동·정밀검사를 취소
- 공식기관 명칭이나 로고를 승인 없이 사용
- 방역기관 연계를 확보하지 못한 상태에서 실시간 출동을 보장
- 농장이나 차량을 공개 순위화하여 낙인·영업피해를 유발
- 공식 결과를 학습데이터로 사용할 권한 없이 2차 활용

## 14.2 공식검사와의 역할 구분

### 1. 결과의 3계층 분리

장치·서비스·공식기관의 결과를 화면, 보고서, API와 계약서에서 일관되게 분리한다.

| 계층 | 허용 결과 | 의미 | 금지 표현 |
|---|---|---|---|
| 장치 검사결과 | Negative·Positive·Invalid·Uncertain | 해당 시료와 키트의 판독상태 | 확진·비감염·안전 |
| 서비스 경보 | NORMAL·WATCH·CAUTION·ALERT | 확인·재검·공식검사 연결 우선순위 | 방역명령·이동허가 |
| 공식 결과 | 관계기관이 정한 공식 판정 | 법정 검사와 조치의 근거 | 민간 시스템의 자동변경 |

NORMAL은 장치와 데이터가 현재 설정된 경보기준을 충족하지 않았다는 뜻일 뿐이다. 감염 부재나 농장 안전을 의미하지 않는다.

### 2. 신속항원검사의 제도상 위치

농림축산식품부 조류인플루엔자 긴급행동지침은 의심농장에서 간이항원진단키트 검사를 의사환축 판정의 참고자료로만 활용하고 반드시 정밀검사를 실시하도록 규정한다.

따라서 본 시스템의 Positive는 공식 확인이 필요한 선별신호이고, Negative는 감염을 배제하는 결과가 아니다. 장치의 목적은 정밀검사를 대체하는 것이 아니라 반복검사와 자동기록을 통해 한정된 공식검사 자원의 우선순위를 지원하는 데 있다.

### 3. 확정할 사용목적 문안

> 본 제품은 가금농장의 분변 Composite Sample을 반복 검사하여 AIV 신속항원키트의 판독결과와 시계열 변화를 기록하고, 관리자 확인·재검 및 공식 정밀검사 연계가 필요한 농장의 우선순위 판단을 지원하는 예찰보조 시스템이다. 본 제품의 결과만으로 조류인플루엔자를 확진·배제하거나 이동제한, 살처분 및 그 밖의 법정 방역조치를 결정하지 않는다.

이 문안은 사업계획상 기준안이다. 최종 표시·광고·사용설명서 문구는 검역본부의 제품분류와 허가범위에 따라 확정한다.

### 4. 규제분류 사전협의 항목

“확진장비가 아니다”라는 설명만으로 규제 적용 여부를 판단하지 않는다. 다음 사항을 제품사양 확정 전에 서면으로 협의한다.

1. 장치 전체와 개별 구성품의 사용목적
2. 동물용의료기기 또는 동물용체외진단의료기기 해당 여부와 품목·등급
3. 상용 AIV 신속항원키트의 허용검체와 실제 Composite Sample의 차이
4. 자동 희석·혼합·침전·상층액 분주가 IFU 사용조건을 변경하는지
5. 키트, 자동전처리, 영상판독과 경보소프트웨어를 하나의 결합제품으로 보는지
6. 판독소프트웨어가 독립제품인지 장치의 일부인지
7. 제조사, OEM사, 키트사, 판매사와 서비스 운영사의 법적 지위
8. 연구시험, 동물임상시험계획 승인, 품목허가·신고와 기술문서 범위
9. 키트·카메라·전처리·알고리즘 변경 시 변경허가·신고 또는 재검증 범위
10. 설치, 수리, 유지보수, 품질기록과 시판 후 불만·회수 체계
11. “조기예찰”, “위험탐지”, “공식검사 우선순위” 등 효능표현의 허용범위
12. 공공실증 단계에서 연구용 장비를 사용할 수 있는 조건과 결과 활용범위

### 5. Gate 0 규제 패키지

2026년 Gate 0에서 다음 자료를 한 묶음으로 준비한다.

- 제품 구성도와 Wet/Dry Zone
- Sample-to-Answer 전체 흐름
- 사용목적·사용자·설치장소·대상동물
- 허용검체와 실제 검체의 비교표
- 상용 키트 IFU와 자동전처리 차이
- 판독·QC·재검·경보 로직
- 장치 결과와 공식검사의 역할구분
- 위해요인과 위험통제 요약
- 임상·성능검증 개요
- 제조·OEM·운영·수리 책임구조
- 표시·광고 문구 초안
- 변경관리 항목 목록
- 검역본부 질의서와 회신이력

사전협의 결과가 제품정의와 충돌하면 하드웨어 제작보다 사용목적·구성·시험계획을 먼저 수정한다.

### 6. 전문기관 검증과 공식결과 Pairing

| 항목 | 요구사항 |
|---|---|
| 기준검사 | RT-qPCR 등 전문기관이 승인한 기준방법 |
| 시료연결 | 동일 개체·동일 농장·근접 시각의 Paired Sample 원칙 |
| 결과관리 | 장치결과와 공식결과를 별도 필드로 보존 |
| 불일치분석 | Sampling, 전처리, Kit Lot, Ct·바이러스량, 판독원인 분리 |
| Blind 운영 | 가능하면 장치판독자와 기준검사 담당자의 결과 사전공유 제한 |
| 변경관리 | 전처리·키트·모델 변경 후 영향평가와 필요한 재검증 |
| 공개범위 | 기관 승인과 계약에 따라 통계·논문·제안서 사용범위 확정 |

### 7. 공식검사 연결 SOP 최소항목

- 신고대상 증상·폐사·생산변화

- 자동재검을 기다리지 않는 즉시 신고조건
- 농장·운영사·지자체 담당자와 대체연락망
- 제공할 최소 데이터와 전송수단
- 장치·검체·폐기물의 현장보존 또는 조작중지
- 공식기관 도착 전 출입·소독·이동관리
- 공식결과 수신 후 장치기록 정정·잠금
- 사후 불일치 분석과 CAPA
- 훈련·모의연락 및 SOP 개정주기

## 14.3 생물안전 및 시료관리

### 1. 기본원칙

본 장치는 농장 분변을 반복 취급하므로 감염성 여부가 확인되지 않은 모든 현장 검체를 잠재적 위해물로 간주한다. 생물안전 수준과 취급절차는 검체의 위해도, 시험기관의 승인, 관련 방역지침과 기관 생물안전위원회의 판단에 따라 정한다.

실제 감염성 AIV를 이용한 성능시험은 일반 개발실이나 정상농장 현장에서 수행하지 않는다.

### 2. 단계별 시험경계

| 단계 | 검체·환경 | 허용 작업 | 필수 조건 |
|---|---|---|---|
| A | 색소·완충액·인공분변 등 비감염성 Mock | 기구동작, 누액, Carry-over, 영상판독 | 일반 개발안전 절차 |
| B | 정상농장 현장·비감염성 운전 | 설치간섭, 채취대표성, 작업성 | 농장동의, PPE, 소독·폐기 SOP |
| C | 실제 분변·비감염성 또는 상태확인 검체 | Matrix, 전처리, 키트 적합성 | 전문기관 계획, 검체인계·기록 |
| D | 감염성 AIV 또는 공식 양성 검체 | 분석성능·임상성능 평가 | 승인된 전문기관·시설·인력·폐기절차 |

단계 C와 D의 구체적 경계는 시험기관이 검체 상태와 위험평가에 따라 확정한다.

### 3. 장치 구획과 오염통제

| 구역 | 포함 구성 | 통제원칙 |
|---|---|---|
| Wet Zone | Scraper, 수집부, 전처리용기, 튜브, 펌프, 분주부 | 일방향 흐름, 검체접촉부 일회용 또는 검증된 세척 |
| Test Zone | 키트 장착·반응·촬영부 | 검체 누출 방지, 키트 식별, 반응시간 통제 |
| Dry Zone | 전원, 제어기, 통신, 사용자 인터페이스 | 검체와 물리적 분리, 비인가 개방 방지 |
| Waste Zone | 사용 키트·튜브·흡수재·보호구 | 밀폐, 용량감지, 인계·폐기 추적 |
| Service Zone | 정비·교체 접근부 | 정비 전 안전상태 확인과 오염표시 |

핵심 원칙은 검체가 Wet Zone에서 Test·Waste 방향으로만 이동하고 Dry Zone이나 계사환경으로 되돌아가지 않도록 하는 것이다.

### 4. 시료 생애주기 관리

1. Sampling Point, 농장, 계사와 채취시각을 Sample ID에 연결한다.
2. 시료량, 분변 상태, 희석비, 혼합·침전시간과 상층액 위치를 기록한다.
3. 키트 제조사, 제품명, Lot, 유효기간, 보관이력을 연결한다.
4. 키트 장착·분주·반응·촬영·판독의 시각을 자동 기록한다.
5. Invalid·Uncertain·재검 시 원시결과를 덮어쓰지 않고 연결관계로 보존한다.
6. 전문기관 이관 검체는 인계자·인수자·용기·온도·시각을 기록한다.
7. 검체 보유기간 종료 또는 폐기결정 후 승인된 방식으로 처리한다.
8. 폐기물의 생성, 임시보관, 반출·인계와 최종처리 기록을 유지한다.

### 5. 현장 보호조치

- 작업자 PPE와 착탈 순서
- 장치 표면·도구·운반용기의 세척·소독
- 사용 소독제의 농도·접촉시간·재질적합성
- 누액감지와 자동 안전정지
- Spill Kit와 유출구역 통제
- 손씻기·장화·차량·출입자 관리
- 현장 작업 전후 점검표
- 정비기사의 농장 간 이동순서와 교차오염 방지
- 소모품·폐기물의 밀폐포장과 보관한도
- 방역기관 지시가 내부 SOP보다 우선한다는 원칙

### 6. 경보 또는 의심상황 발생 시

1. 불필요한 장치 개방과 추가 시료조작을 중지한다.
2. 현장 담당자는 임상·폐사·생산변화를 확인하되 직접 진단행위를 확대하지 않는다.
3. 신고요건에 해당하면 재검을 기다리지 않고 공식 신고절차를 수행한다.
4. 장치·검체·폐기물은 관계기관 지시에 따라 보존·봉인·소독 또는 폐기한다.
5. 원격 유지보수도 현장통제에 영향을 주면 일시 중지한다.
6. 공식기관에 최근 결과, Sample ID, Kit Lot, 장치상태와 출입·정비이력을 제공한다.
7. 상황 종료 후 생물안전·장치성능·데이터 무결성에 대한 사건검토와 CAPA를 실시한다.

### 7. 즉시 중단조건

- 감염성 검체 또는 오염물이 Dry Zone·작업자·농장환경으로 누출
- 음성 Blank에서 반복 신호가 발생하여 Carry-over를 배제할 수 없음
- 일회용 검체접촉부 분리가 실패해 현장에서 반복적인 내부세척이 필요
- PPE·소독·폐기물 보관 및 인계절차를 이행할 수 없음
- 관계기관 또는 시험기관이 시험중지를 요구
- Sample ID·Kit Lot·공식결과의 추적성이 상실
- 장치 정비가 농장 간 오염전파 가능성을 통제하지 못함

중단 후 재개는 원인분석, 오염제거, CAPA와 책임기관의 승인을 완료한 뒤 결정한다.

## 14.4 데이터 관리

### 1. 데이터 분류

농장 관련 데이터 전체를 일괄적으로 개인정보로 보거나 모두 공개정보로 취급하지 않는다. 필드별로 개인정보성, 영업기밀성, 방역민감도와 공식기록 여부를 평가한다.

| 데이터군 | 예시 | 주요 위험 | 기본 통제 |
|---|---|---|---|
| 장치 | 장치 ID, 상태, 고장, 설정, 버전 | 위·변조, 원격제어 | 장치인증, 서명업데이트, 감사로그 |
| 시료·검사 | Sample ID, C/T 이미지·값, QC, 재검 | 결과변조, 오판 | 원본보존, 시간동기화, 변경이력 |
| 농장 | 농장 ID, 위치, 축종, 사육규모 | 낙인, 영업피해 | 최소공개, 가명키, 역할별 접근 |
| 사람 | 담당자, 연락처, 계정, 접속기록 | 개인정보 침해 | 처리근거, 최소수집, 권리보장 |
| 이동·출입 | 차량식별, 방문시각, GPS·경로 | 재식별, 방역정보 노출 | 목적제한, 세분권한, 보유기간 |
| 공식결과 | 정밀검사, 방역조치, 역학정보 | 권한침해, 오해 | 공식출처 표시, 별도권한, 잠금 |
| 사업운영 | 계약, SLA, 유지보수, 비용 | 상업정보 유출 | 계약권한, 비밀유지, 접근통제 |
| 모델 | Feature, Label, 버전, 임계값 | Label Leakage, 성능왜곡 | 데이터계보, 버전관리, 검증승인 |

### 2. 데이터 처리 기본원칙

1. 처리목적과 법적 근거를 데이터 항목별로 기록한다.
2. 목적에 필요한 최소 항목만 수집한다.
3. 수집 당시 고지한 목적을 벗어난 2차 이용은 별도 검토한다.
4. 개인정보, 농장 영업정보와 공식 방역정보를 논리적으로 분리한다.
5. 농장·기관·운영사·연구기관의 소유권과 이용권을 계약서에 구분한다.
6. 원시데이터와 수정·정제·모델입력 데이터를 구분하고 계보를 유지한다.
7. 보유기간이 끝나거나 목적이 달성되면 파기하고 필요한 법정기록은 분리 보관한다.
8. 정보주체와 데이터 제공기관의 열람·정정·반출·삭제 요청절차를 마련한다.
9. 위탁·재위탁·클라우드·국외이전 여부를 사전에 공개하고 계약에 반영한다.
10. 개인정보보호법과 공공기관의 보안·영향평가 요구사항을 도입기관별로 확인한다.

### 3. 접근권한과 보안통제

| 통제영역 | 최소 요구사항 |
|---|---|
| 신원 | 사용자·장치별 고유 ID, 공유계정 금지, 강한 인증 |
| 권한 | 농가·운영사·전문기관·지자체 역할별 최소권한 |
| 전송 | 장치–서버–사용자 구간 암호화와 인증서 관리 |
| 저장 | 민감정보 암호화, 키 분리, 백업·복구시험 |
| 기록 | 로그인, 조회, 다운로드, 설정·모델·결과 변경 감사로그 |
| 업데이트 | 서명된 소프트웨어, 승인·롤백·취약점 대응 |
| 단말 | 불필요한 포트·서비스 비활성화, 물리적 봉인 |
| 모니터링 | 비인가 접근, 대량반출, 시간오류, 설정변경 탐지 |
| 사고 | 격리, 증거보존, 통지·신고, 복구와 재발방지 |
| 종료 | 계약종료 시 계정회수, 데이터 반환·파기확인 |

보안통제는 장치 출시 시점의 일회성 점검이 아니라 지원기간 전체의 운영의무로 본다.

### 4. 공식 데이터 연계조건

다음 조건이 모두 확인되기 전에는 KAHIS, 축산차량 이동정보, 공식검사 또는 역학정보의 자동연계를 사업성과로 확정하지 않는다.

- 제공기관과 제공권한이 명확함
- 법적 근거·동의·계약 등 적법한 처리근거가 있음
- 목적과 필요한 최소 필드가 정의됨
- 실시간성·정확성·갱신주기와 책임한계가 합의됨
- 저장위치, 보유기간, 재제공과 파기조건이 정해짐
- 사용자·기관별 접근권한과 감사방법이 마련됨
- 연계중단 시 서비스의 안전한 대체절차가 있음
- 모델학습과 사업홍보 등 2차 활용범위가 별도로 승인됨

공식 데이터 연계가 지연되더라도 장치의 기본 검사·QC·재검·기록 기능은 독립적으로 운영할 수 있어야 한다.

### 5. 알고리즘과 모델 관리

- 모델 입력, Feature 정의, Label 출처와 제외조건을 문서화한다.
- 공식결과가 생성된 이후의 정보를 사전예측 Feature로 사용하는 Label Leakage를 방지한다.
- 농장·시기·Kit Lot별 데이터 분할로 과적합을 점검한다.
- 경보마다 주요 근거코드와 최근 변화추세를 제공한다.
- 모델 버전, 임계값, 배포일, 승인자와 롤백 버전을 기록한다.
- 데이터 분포·무효율·위양성·위음성·드리프트를 모니터링한다.
- 모델 변경이 검사·경보 성능이나 허가범위에 영향을 주면 영향평가와 재검증을 수행한다.
- 공식 방역조치를 완전자동화하지 않고 사람의 검토와 기존 법정절차를 유지한다.

초기 단계에서는 복잡한 AI 모델보다 규칙기반 QC·재검·시계열 기준선을 우선 적용하고, 충분한 Label과 외부검증을 확보한 뒤 모델을 확장한다.

### 6. 계약서에 명시할 데이터 항목

- 개인정보처리자·수탁자와 각 기관의 역할
- 데이터 목록, 처리목적과 법적 근거
- 수집·조회·다운로드·제공 권한
- 원시데이터와 파생데이터의 소유·이용권
- 보유기간, 반환, 파기와 파기확인
- 재위탁·클라우드·국외이전
- 보안사고 통지시간과 책임분담
- 연구·논문·특허·홍보·모델학습 사용범위
- 계약종료 후 서비스 연속성과 데이터 이동성
- 감사, 현장점검과 위반 시 시정·중단권한

### 7. 데이터 사고 대응

1. 영향을 받은 계정·장치·연계를 격리한다.
2. 로그와 원본을 보존하고 임의 삭제·수정을 금지한다.
3. 유출·변조·오경보·서비스중단 범위를 구분한다.
4. 개인정보와 공식 방역정보의 통지·신고 의무를 검토한다.
5. 농가·수요기관·전문기관에 승인된 절차로 알린다.
6. 안전한 버전으로 복구하고 결과 무결성을 재검증한다.
7. 원인과 CAPA를 기록하고 재발방지 확인 후 재개한다.

## 14.5 공공 도입 가능성

### 1. 공공 도입의 판단기준

공공기관이 본 시스템을 도입하려면 기술의 신기성보다 다음 질문에 답할 수 있어야 한다.

- 무엇을 탐지하며 공식검사와 어떻게 구분되는가?
- 장치 경보가 실제 방역업무의 시간을 줄이거나 우선순위를 개선하는가?
- 위음성·오경보·Invalid·장애가 발생했을 때 안전하게 복구되는가?
- 시료·폐기물·농장·개인정보가 적법하고 안전하게 관리되는가?
- 장치·소모품·통신·출동·유지보수의 총비용이 예산범위 안에 있는가?
- 제조·OEM·키트·운영·수리·사고의 책임이 계약으로 구분되는가?
- 전문기관의 독립 검증과 현장 사용성 자료가 있는가?
- 사업 종료 후에도 데이터 반환, 장비철거와 운영종료가 가능한가?

공공 도입 가능성은 “관심기관 수”가 아니라 검증자료, 유료계약, 재계약과 실제 업무개선으로 평가한다.

### 2. 단계별 도입경로

| 단계 | 목적 | 주요 계약·제도 | 진입조건 | 완료증거 |
|---|---|---|---|---|
| 1. 공동기획 | 문제·업무흐름 확인 | NDA, 자문·협력의향 | 사용부서·전문기관 확보 | 요구사항·역할표 |
| 2. 연구검증 | Mock·전문기관 성능 확인 | 연구개발·시험용역 | Gate 0, 시험계획 승인 | 시험성적·위험통제 |
| 3. 제한실증 | 정상농장 운영성과 확인 | 유료실증·임대·서비스 | 생물안전·데이터·SOP | 가동률·사용성·원가 |
| 4. 지역실증 | 공공 업무연계 검증 | 지자체 실증·정책사업 | 공식검사 연결, 책임계약 | 공공성과·완료보고 |
| 5. 초기조달 | 소규모 구매 접근성 확보 | 벤처나라 등 | 기업·제품·품질·목록요건 | 등록·납품·검수 |
| 6. 혁신조달 | 공공실증 확대 | 혁신제품·시범구매 | 기술개발단계·혁신성·조달적합성 | 지정·매칭·성공평가 |
| 7. 정규사업 | 반복구매·지역확산 | 경쟁계약·협상계약·기타 적법한 방식 | 규격·예산·운영성과 | 재계약·확산·SLA |

각 단계는 자동 승급하지 않는다. 이전 단계의 Gate와 수요기관 예산·계약검토를 통과해야 다음 단계로 진행한다.

### 3. 벤처나라 활용

벤처나라는 창업·벤처기업 제품의 초기 공공판로로 활용할 수 있다. 다만 다음 요건을 별도로 충족해야 한다.

- 창업·벤처기업 자격
- 직접생산 또는 국내 제조기업을 통한 적법한 OEM 생산
- 기술·품질심사
- 입찰참가자격
- 물품목록번호
- 벤처나라 상품등록
- 지정·등록기간과 주문한도 준수

조달청 안내상 등록제품은 6년간 바로주문·견적주문 방식으로 공급할 수 있고, 표시된 추정가격 기준은 2천만원 이하이며 일부 기업유형은 5천만원 이하이다.

따라서 기존 사업안의 10농가·1차년도 약 1억 2,500만원 전체를 벤처나라 소액구매로 전제하지 않는다. 실제 계약은 수요기관의 계약목적, 물품·용역 구분, 추정가격, 예산과 관련 법령에 따라 조달담당자와 검토한다. 한 사업을 계약한도에 맞추기 위한 인위적인 분할은 적용하지 않는다.

### 4. 혁신제품과 시범구매

본 시스템은 스마트팜, 인공지능, 바이오헬스와 안전 분야의 공공문제 해결형 제품으로 검토할 수 있다.

조달청 혁신시제품은 상용화 직전의 기술개발단계 7 이상 제품·서비스를 대상으로 공공성·혁신성 평가와 조달적합성 검토를 거쳐 지정한다. 공급자제안형과 수요자제안형을 활용할 수 있다.

지정 후에도 구매가 자동 확정되는 것은 아니다.

- 수요기관이 자체예산으로 직접 구매하거나
- 조달청 시범구매사업에 신청하고
- 수요조사, 기관·기업 매칭, 계약, 현장테스트, 완료보고와 성공평가를 거친다.

본 사업은 2026~2027년 부품·Alpha 단계에서 혁신제품 지정을 서두르기보다, 2028년 전문기관 검증과 제한실증 자료를 확보한 뒤 신청 가능성을 판단한다.

### 5. 구매대상 정의

공공계약 전에 제품을 다음 단위로 분리하여 원가와 책임을 명확히 한다.

| 계약대상 | 포함범위 |
|---|---|
| 장치 | Sampling Unit, Analysis Unit, 제어·통신부, 설치부품 |
| 초기설치 | 현장조사, 설치, 시운전, 교육, 인수시험 |
| 소모품 | 키트, Wet Zone 카트리지, 튜브, 흡수재, 폐기용기 |
| 플랫폼 | 계정, 대시보드, 알림, 데이터저장, API |
| 운영서비스 | 원격모니터링, 정기점검, 현장출동, 보고서 |
| 전문검증 | 기준검사, 검체관리, 통계분석, 시험성적 |
| 보안·데이터 | 로그, 백업, 사고대응, 데이터 반환·파기 |
| 철거·종료 | 오염확인, 장비회수, 계정폐기, 데이터 이전 |

물품·용역을 분리하거나 묶는 방식은 기술편의가 아니라 수요기관의 실제 구매목적과 계약법령에 따라 결정한다.

### 6. 공공 제안서 필수 증거

- 제품 사용목적과 공식검사 역할구분
- 검역본부 규제분류·사전협의 기록
- 전문기관 시험계획과 성적
- Sampling·전처리·키트·영상판독의 추적성
- 위음성·오경보·Invalid·Carry-over 결과
- 장치 가동률, MTTR, 통신·정전 복구
- 생물안전·폐기물·현장출입 SOP
- 개인정보·농장정보 처리계획과 보안통제
- 장애·경보·공식검사 연결 RACI
- 설치·소모품·플랫폼·출동을 포함한 TCO

### 9. 공공 도입 Go/No-Go

#### Go 조건

- 제품분류와 사용목적이 서면으로 확인됨
- 상용 키트의 허용검체·전처리 결합문제가 해소됨
- 전문기관 비교검증에서 목표성능과 불확실성이 공개됨
- 공식검사 연결 SOP와 담당기관이 확정됨
- 생물안전·폐기물·정비절차가 현장에서 실행 가능함
- 데이터 처리근거·권한·보유·파기와 보안통제가 계약화됨
- 실측 TCO가 수요기관 예산과 지불의사에 부합함
- 제조·OEM·키트·유지보수 공급망과 제품책임이 확정됨
- 유료실증 또는 수요기관의 구체적인 구매의사가 확인됨

#### No-Go 또는 수정 조건

- 규제분류가 미확정인데 상용 판매를 요구
- 공식 양성 대비 위음성이 반복되고 보완 가능한 조건을 찾지 못함
- 장치 음성이 신고 또는 공식검사를 지연할 가능성이 큼
- 감염성 검체의 안전한 시험·폐기경로를 확보하지 못함
- 공식 데이터 접근권한이 없는데 이를 핵심 성능의 전제로 사용
- 오경보·Invalid·장애가 공공업무 부담을 오히려 증가시킴
- 10농가 운영원가가 예산과 지불의사를 지속적으로 초과
- 무상실증만 반복되고 유료계약·재계약 근거를 확보하지 못함
- 조달제도 지정이 구매를 보장한다는 전제에 의존

No-Go는 사업 전체 폐기만을 의미하지 않는다. 필요하면 제품역할을 자동 시료관리, 키트 판독품질관리, 검사기록과 전문기관 업무지원으로 축소한다.

## 최종 원칙

> **공식체계와 경쟁하지 않고, 공식체계가 더 빠르고 일관되게 움직일 수 있도록 검증된 선행정보를 제공한다.**

본 장의 법령·지침·조달기준은 작성일 현재의 제도 검토를 위한 기준이다. 실제 시험, 허가, 판매, 데이터 제공과 공공계약 착수 전에는 농림축산검역본부, 전문기관, 개인정보·법률 담당자와 해당 수요기관의 조달담당자를 통해 최신 규정과 적용범위를 다시 확인한다.
